# بازارینو — بازار همه‌چیز
یک قالب مدرن و قابل توسعه برای بازار آنلاین چندفروشنده.

## اجرای سریع
فایل `index.html` را با Chrome باز کنید.

## امکانات نسخه فعلی
- صفحه اصلی مدرن و واکنش‌گرا
- جستجو و دسته‌بندی
- عضویت آزمایشی با شماره تلفن، نام کاربری و نام
- ثبت محصول با عکس، نام، مشخصات، قیمت، موقعیت و راه ارتباطی
- نمایش آگهی‌ها و راه ارتباط با فروشنده
- ذخیره داده‌ها در LocalStorage مرورگر

## برای تبدیل به سایت واقعی
این نسخه Front-end است. برای یک بازار بزرگ واقعی باید Backend و Database اضافه شود:
- ثبت‌نام با OTP واقعی SMS
- حساب کاربری و احراز هویت
- آپلود امن تصاویر در فضای ابری
- دیتابیس محصولات و کاربران
- پنل مدیریت و گزارش آگهی
- چت خریدار و فروشنده
- پرداخت آنلاین در صورت نیاز
- سیستم گزارش/مسدودسازی و قوانین
- API و امنیت سرور
